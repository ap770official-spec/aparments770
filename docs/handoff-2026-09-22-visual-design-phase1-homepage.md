## הפלטה (נדגמה בפועל מקובצי התדמית, לא מוערכת)

הוסיפו את אלה כמשתני CSS ב-`src/app/globals.css`, תחת `:root` וב-`@theme
inline` (בדיוק כמו `--color-background`/`--color-foreground` הקיימים שם
היום), כדי שאפשר יהיה להשתמש בהם כ-`bg-brand`, `text-brand` וכו' בכל
הפרויקט:

| שם טוקן מוצע | ערך | שימוש |
|---|---|---|
| `--color-brand` | `#6e4e37` | חום-קפה — כפתורי חיפוש, מצב פעיל של פילטרים, לוגו |
| `--color-brand-foreground` | `#ffffff` | טקסט על גבי `--color-brand` |
| `--color-accent-whatsapp` | `#256240` | ירוק — כפתורי וואטסאפ בלבד (לא לשנות בשלב הזה, רק לתעד כטוקן) |
| `--color-placeholder` | `#d8cfc0` | בז' — placeholder לתמונות שעוד לא הועלו |
| `--color-ink` | `#1a1512` | כמעט-שחור — תגי מרחק, טקסט כהה מודגש |

שימו לב: יש כבר `--background`/`--foreground` קיימים ב-`globals.css` (כולל
גרסת מצב כהה תחת `@media (prefers-color-scheme: dark)`) — **לא למחוק
אותם**, רק להוסיף את הטוקנים החדשים לצידם. אם מצב כהה קיים כבר בקוד, לוודא
שהטוקנים החדשים מקבלים גרסה סבירה למצב כהה גם הם (למשל `--color-brand`
יכול להישאר זהה, הוא כהה ועובד גם על רקע כהה).

## טיפוגרפיה

בתדמית, הלוגו והכותרות הראשיות מעוצבים בפונט **serif אלגנטי** (שונה
מהטקסט הרגיל, שהוא sans-serif). כרגע האתר טוען את הפונט `Geist` (ב-
`src/app/[locale]/layout.tsx`) אבל **רק עם `subsets: ["latin"]`** — אין לו
תווים עבריים בכלל, ובכל מקרה ה-`body` ב-`globals.css` דורס אותו ידנית
ל-`Arial, Helvetica, sans-serif`.

להוסיף פונט serif חדש שתומך גם בעברית וגם באנגלית — מומלץ **Frank Ruhl
Libre** מ-Google Fonts (`next/font/google`, יש לו גם `subsets: ["latin",
"hebrew"]`), ולהשתמש בו רק לכותרות/לוגו (לא לכל הטקסט — הטקסט הרגיל נשאר
sans-serif כמו היום, זה תואם למה שרואים בתדמית).

```tsx
// src/app/[locale]/layout.tsx
import { Frank_Ruhl_Libre } from "next/font/google";

const frankRuhl = Frank_Ruhl_Libre({
  variable: "--font-serif-brand",
  subsets: ["latin", "hebrew"],
});
```
ולהוסיף את המשתנה ל-`className` של ה-`<html>` (לצד `geistSans.variable`
הקיים), ולהגדיר `--font-serif-brand` כטוקן ב-`@theme inline` (בדומה
ל-`--font-sans`/`--font-mono` הקיימים) כדי שאפשר יהיה להשתמש ב-`font-serif-
brand` כ-class ב-Tailwind.

## מה לשנות בפועל (דף הבית בלבד)

### 1. `src/components/Header.tsx` (רכיב משותף — משפיע על כל האתר, וזה בכוונה: המיתוג צריך להיות אחיד בכל מקום)
- הלוגו "Apartments770" (שורה 32) — לעצב בפונט ה-serif החדש, ובצבע
  `--color-brand`. אפשר גם לשקול לפצל ל"770" (חום, מודגש) + "Apartments"/
  "דירות" (רגיל) — בדיוק כמו בתדמית — אבל זה שיפור אסתטי, לא חובה בשלב 1.

### 2. `src/app/[locale]/page.tsx` (דף הבית)
- הכותרת הראשית (`t("title")`, שורה 22 היום) — לעצב בפונט ה-serif.
- שאר הטקסט (`t("about")`) נשאר sans-serif רגיל, בהתאם לתדמית.

### 3. `src/components/SearchForm.tsx`
- כפתור הטריגר שפותח את הלוח (השדה הסגור "בחרו תאריכים") — לעצב עם מסגרת
  מעוגלת יותר (`rounded-full` או `rounded-xl` לפי מה שנראה הכי קרוב
  לתדמית) בהשראת שורת החיפוש בתדמית.
- כפתור השליחה (`t("submit")`, "חפש") — לצבוע ברקע `--color-brand` במקום
  `bg-foreground` הנוכחי, עם עיגול/פינות מעוגלות דומה לכפתור החיפוש
  בתדמית (בתדמית זה בכלל עיגול עם אייקון זכוכית מגדלת — לשלב הזה מספיק
  כפתור מלבני מעוגל בצבע הנכון, לא חובה להוסיף אייקון).
- שדה "מספר אורחים" — לעדכן border-radius/צבעים בהתאם לשאר הטופס, בלי
  לשנות את הלוגיקה.

### 4. מה לא לגעת בו בשלב הזה
- שום דבר בעמוד `/search` (תוצאות חיפוש), עמוד דירה, דשבורד בעלים, פאנל
  ניהול — אלה שלבים הבאים.
- הלוח עצמו (`DayPicker`, סימון החגים) — הלוגיקה נשארת בדיוק כמו שהיא,
  אפשר לעדכן רק צבעים/עיגולים דרך ה-CSS הקיים ב-`globals.css`
  (`.rdp-root`, `.rdp-holiday` וכו') כדי שיתאים לפלטה החדשה.
- כפתורי וואטסאפ בשאר האתר (עדיין ירוקים, לא חלק משלב 1).

## בדיקת קבלה (לפני push)
1. `npm run lint` ו-`npm run build` עוברים נקי.
2. בדף הבית: הלוגו והכותרת בפונט serif, בצבע החום `#6e4e37`.
3. הכותרת/לוגו מוצגים תקין גם בעברית וגם באנגלית (לוודא שהפונט אכן תומך
   בעברית — לא "תיבות ריקות" / fallback שבור).
4. כפתור "חפש" בצבע החום, לא בשחור כמו היום.
5. מצב כהה (dark mode) עדיין קריא — הטקסט לא נעלם על רקע כהה.
6. שום פונקציונליות לא נשברה (חיפוש עדיין עובד, הלוח עדיין נפתח/נסגר
   ומסמן חגים).
