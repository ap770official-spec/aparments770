# משימה להעברה ל-Claude Code — לוח השנה צריך להיות סגור כברירת מחדל

**נוצר:** 22 בספטמבר 2026
**מקור:** סוכם בצ'אט ניהול נפרד, הועבר לביצוע בצ'אט הזה.

לפני שמתחילים: `git pull` על הענף `claude/apartments770-basic-setup-oqzbfi` (הענף
שמפרסם את האתר החי).

---

## מה הבעיה

תכונת לוח השנה עם החגים (`docs/handoff-2026-09-22-calendar-date-picker.md`,
כבר בנויה ועובדת נכון — נבדק ואומת) נבנתה כך שה-`<DayPicker>` תמיד **פתוח
וגלוי** בתוך הטופס, ברגע שנכנסים לדף הבית — תופס המון מקום ולא מרגיש כמו
אתר הזמנות רגיל (טיסה/מלון), שם רואים שדה קטן וסגור ("בחרו תאריכים"), ורק
בלחיצה עליו נפתח לוח השנה כחלון צף.

## מה לשנות

בקובץ `src/components/SearchForm.tsx`: לעטוף את ה-`<DayPicker>` הקיים
(השאירו אותו כמו שהוא — כולל סימון החגים, מצב `range`, הזרימה קליק-קליק) ב-
**popover סגור כברירת מחדל**:

1. **שדה טריגר** — כפתור/תיבה שמציגה:
   - כשאין עדיין תאריכים נבחרים: טקסט placeholder (`t("dates")` / "בחרו
     תאריכים").
   - אחרי שנבחר טווח מלא: את התאריכים שנבחרו (בדיוק הפורמט שכבר קיים בשורה
     `${t("checkin")}: ... · ${t("checkout")}: ...`).
2. **לחיצה על השדה** פותחת את הלוח כ-dropdown/popover צף מתחתיו (לא צריך
   ספריית popover חדשה — `position: absolute` + `z-index` + state בוליאני
   `isOpen` מספיקים לצורך זה, בדומה לתבניות קיימות אחרות בפרויקט).
3. **סגירה אוטומטית** כשנבחר טווח מלא (`range?.from && range?.to`) — מיד
   אחרי הבחירה השנייה (checkout), לסגור את ה-popover לבד, בלי צעד נוסף.
4. **סגירה בלחיצה מחוץ ללוח** (click-outside) — כדי שאפשר יהיה גם לסגור
   ידנית בלי לבחור טווח.
5. נגישות בסיסית: אפשר לסגור גם עם `Escape`.

## מה לא לשנות
- שום דבר בלוגיקת הבחירה עצמה, סימון החגים, `@hebcal/core`, ה-query params
  שנשלחים ל-`/search` — הכל כבר עובד נכון, זו רק עטיפה ויזואלית (UI shell)
  סביב הרכיב הקיים.
- לא לגעת ב-`hebrewHolidays.ts`.

## בדיקת קבלה (לפני push)
1. `npm run lint` ו-`npm run build` עוברים נקי.
2. בכניסה לדף הבית — הלוח **סגור**, רואים רק שדה/כפתור קטן.
3. לחיצה על השדה פותחת את הלוח.
4. בחירת checkin ואז checkout סוגרת את הלוח אוטומטית ומציגה את שני
   התאריכים בשדה.
5. לחיצה מחוץ ללוח (לפני שנבחר טווח מלא) סוגרת אותו.
6. עובד גם ב-`/he` (RTL) וגם ב-`/en` (LTR).
